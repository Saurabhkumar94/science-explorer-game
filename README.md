# Science Explorer Game - Digital Companion 
**Chapter 01 | The Wonderful World of Science | Class 6 Science**

An interactive digital learning companion built with Next.js 15 and Tailwind CSS v4, designed to accompany the physical **Curiosity Lab Starter Kit**.

---

##  Features

- **7 Screen Guided Journey:** From student onboarding to custom science pledges and teacher diagnostic dashboard.
- **Rule-Based Engine:** Completely lightweight validation for tracking scores out of 15 questions across 3 core modules.
- **Tailwind CSS v4 & PostCSS:** Optimized with the latest `@tailwindcss/postcss` compiler.
- **State Persistence:** Automatically saves progress locally (`localStorage`) with a unified `game_01_` prefix.

---

##  Tech Stack

- **Framework:** Next.js 15 (App Router, TypeScript)
- **Styling:** Tailwind CSS v4, PostCSS
- **Animations:** HTML5 canvas-confetti, custom tailwind shake effects
